The installed wallpaper's `roms` folder is managed by the companion Manager.
Do not copy games here by hand unless you are maintaining an existing install.

In the Manager, choose one source folder containing your legally obtained ROMs.
It scans that folder and all subfolders, then copies recognized games into the
configured system folders and updates `library.local.json`. System-named source
folders such as `n64`, `nes`, or `psx` help resolve shared extensions.

Supported formats are listed in the Manager and in `docs/PLATFORM_MATRIX.md`.
RetroSignal does not include games.
