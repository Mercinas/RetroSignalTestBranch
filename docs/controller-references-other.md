# Controller illustration references — Atari, NEC, Sony and Philips

`manager/controller-layouts/art-other.js` supplies original inline vector illustrations in a 600 × 340 coordinate space. Photographs are reference material, not bundled assets. Mapping identities remain the existing `layouts.js` inputs; this illustration change does not establish new emulator support.

| System | Depicted hardware | Reference |
|---|---|---|
| Atari 2600 | CX40 joystick; Select/Reset separated into a console-switch inset | [Evan-Amos original hardware photograph](https://commons.wikimedia.org/wiki/File:Atari-2600-Joystick.jpg) |
| Atari 5200 | CX52 analog joystick, three function keys, numeric keypad, duplicate side fire buttons | [Atari 1983 owner manual](https://www.ataricompendium.com/archives/manuals/5200/atari_5200_83_rev_a.pdf), [Evan-Amos photograph](https://commons.wikimedia.org/wiki/File:Atari-5200-Controller.jpg) |
| Atari 7800 | Narrow CX24 Pro-Line with a fire button on each side; console switches in a separate inset | [Atari original owner manual](https://archive.org/details/Atari_7800_Pro_System_Owners_Manual_1987_Atari_US_Rev_A), [Marcin Wichary hardware photograph](https://commons.wikimedia.org/wiki/File:Atari_and_Commodore_joysticks_(2203293750).jpg) |
| TurboGrafx-16 / TurboGrafx-CD | Two-button TurboPad with separate I/II turbo sliders | [Evan-Amos original hardware photograph](https://commons.wikimedia.org/wiki/File:NEC-TurboGrafx-16-Controller-FL.jpg) |
| Atari Jaguar | Original three-button PowerPad, twelve-key pad, Pause/Option | [Original controller photograph](https://commons.wikimedia.org/wiki/File:Atari-Jaguar-Controller-Original.png), [Evan-Amos standard controller photograph](https://commons.wikimedia.org/wiki/File:Atari-Jaguar-Controller.jpg) |

| Philips CD-i | 22ER9051 thumbstick remote, illustrative only | [Philips CDI 350 service manual, printed page 5 / PDF page 6](https://icdia.co.uk/svcmanuals/cdi350.pdf), [Philips CDI 220/00 service manual, controls section](https://www.manualslib.com/manual/1427143/Philips-Cdi-220-00.html?page=4) |

Physical face buttons use proportionate visible dimensions; the integrating renderer may expand transparent hit regions. Console and rear shoulder controls are explicitly separated. Turbo sliders, unverified 5200/Jaguar keypad keys, unused remote controls and power/screen controls are decorative and cannot acquire mappings. The CD-i mapping control set remains empty.

Validation at handoff: module import succeeded and all controls of these nine standard layouts had geometry (7/7/9/8/8/0/9/14/9 respectively). Source photo/manual pages were browsed. After an initially blocked reference download, native pixels were inspected for the Lynx II (root-materialized photograph `dist/controller-lynx-reference.png`) and CD-i remote (original manual downloaded to a temporary folder and rendered through Poppler). Lynx II was corrected to the photographed upper B/A diagonal, lower duplicate B/A diagonal, vertical side-of-screen power/option keys, right speaker and bowed casing. The remote was corrected to four curved action keys surrounding its thumbstick, eight playback/volume keys, tapered lower shell and no fictitious slider. Integration owner owns final UI acceptance and mapping interaction checks.
