# Nintendo controller artwork references

The six SVG drawings in `manager/controller-layouts/art-nintendo.js` are original, unbranded diagrams for mapping controls. They use observed hardware shapes and relative placement; they are not CAD drawings. No downloaded photograph is shipped in the application. References checked 2026-10-01.

| System / illustrated model | Visual reference | Geometry carried into the diagram |
| --- | --- | --- |
| NES original rectangular pad | [Nintendo hardware history](https://www.nintendo.com/en-gb/Hardware/Nintendo-History/Nintendo-Entertainment-System/Nintendo-Entertainment-System-627024.html), especially `nes_controller_en.jpg` | Light rectangular shell, dark faceplate, left cross, centred horizontal Select/Start, two small red circular B/A buttons on the same horizontal line. |
| Super NES European / Super Famicom four-colour pad | [Nintendo hardware history](https://www.nintendo.com/en-gb/Hardware/Nintendo-History/Super-Nintendo/Super-Nintendo-627040.html), `snes_controller_en.jpg` | Rounded twin lobes, small angled Select/Start, top shoulders, face-button diamond X blue / Y green / A red / B yellow. Regional colour choice is stated in the art name. |
| Nintendo 64 original grey pad | [Original overhead photograph by Evan-Amos](https://commons.wikimedia.org/wiki/File:Nintendo-64-Controller-Gray-Flat.jpg); [Nintendo button identification](https://en-americas-support.nintendo.com/app/answers/detail/a_id/56673/~/nintendo-64-controller-diagram) | Near-square three-grip silhouette, raised top-centre housing, extended centre prong, small start button, B above-left of A, four smaller C buttons, octagonal stick gate. The newer official diagram was used only for legacy button names, not its added wireless controls. |
| Game Boy original DMG | [Nintendo original-system dimensions](https://www.nintendo.com/en-gb/Support/Legacy-system/Technical-data-619585.html); [Evan-Amos original hardware photograph](https://commons.wikimedia.org/wiki/File:Game-Boy-Original.png) | Tall 90:148 shell proportions, grey inset screen, burgundy A above-right of B, angled Select/Start and diagonal speaker slots. |
| Game Boy Advance original AGB | [Nintendo hardware history](https://www.nintendo.com/en-gb/Hardware/Nintendo-History/Game-Boy-Advance/Game-Boy-Advance-627139.html), `gba_en.jpg`; [Nintendo manuals](https://en-americas-support.nintendo.com/app/answers/detail/a_id/16961/~/nintendo-gamecube-and-game-boy-advance-manuals) | Wide curved body, 3:2 screen, D-pad left, A above-right of B, Start above Select below the left D-pad, twin upper shoulder buttons and right speaker. |
| Virtual Boy original twin-D-pad pad | [Original controller photograph](https://commons.wikimedia.org/wiki/File:Virtual_Boy_controller.png) | Two separate teardrop faces, matching D-pads, grey Select above-left of Start, red A above-right of B, long outer grips and central battery box. Both rear triggers are placed in a separate labelled underside callout. |

Nintendo hardware photographs, the original N64 overhead photograph, original Game Boy photograph, and Virtual Boy photograph were viewed as actual pixels. The temporary reference copies remain outside the repository. The original Virtual Boy photograph is used only to observe hardware; its pixels are not incorporated into SVG.

Input IDs remain those already declared in `layouts.js`. In particular, Nintendo 64 stick directions are 16–19 and C directions 20–23; Virtual Boy right-pad directions remain 16–19. No new peripheral inputs are invented. N64 Z is shown in a separate underside callout. Footprints describe the small visible physical controls; the renderer supplies larger invisible hit targets and selection outlines independently.

Validation performed by the artwork owner: module syntax; every declared control has an art footprint for all six systems (8 NES, 12 SNES, 18 N64, 8 GB, 10 GBA, 14 Virtual Boy). Integration owner performs rendered UI and interaction acceptance at desktop and narrow widths.
